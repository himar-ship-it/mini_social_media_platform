# 🌐 Mini Social Media Platform

A lightweight, full-stack mini social media web application designed for seamless user interaction, real-time engagement, and profile management.

---

## ✨ Key Features

* **User Profiles & Account Switching:** Switch between mock user profiles to test distinct dynamic feeds, bios, avatars, and follower counts.
* **Posts & Content Feed:** Create rich text posts with optional image link attachments.
* **Likes & Comments System:** Interactive like/unlike toggling and real-time threaded comment sections under every post.
* **Follow/Unfollow Engine:** Dynamic follow system that updates follower/following metrics instantly.
* **Data Persistence:** Uses browser `localStorage` to keep posts, comments, likes, and profile changes intact across page refreshes.
* **Backend Architecture Schemas:** Includes REST API blueprints and database models for both Express.js (Node.js) and Django (Python).

---

## 🛠️ Built With

* **Frontend:** HTML5, JavaScript (ES6+)
* **Styling:** Tailwind CSS, FontAwesome Icons
* **Data Handling:** Browser `localStorage` API
* **Backend Blueprints:** Express.js / Django REST Framework with PostgreSQL / MongoDB schemas
